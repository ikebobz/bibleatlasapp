# Mobile reader: one bottom bar and a map peek

## What changes

1. **One compact reading bar during audio use.** On phones, once chapter audio starts, replace the separate chapter and audio bars with one bottom bar: previous chapter, play/pause, current chapter picker, next chapter. Keep each target at least 44px and show the playing/loading state. Pausing keeps the combined bar in place until the reader leaves the chapter or closes the audio session, avoiding a layout jump. The chapter picker remains the existing book/chapter sheet. Audio that is unavailable stays in the current non-playing layout with a clear status; tablet/desktop playback keeps its current controls. Keep seeking, skip, speed, autoplay and mute accessible through an audio-options panel opened from the compact bar, rather than deleting them. Chapter-end links and swipe navigation remain.
2. **Reserve exactly the space used.** Coordinate the reader-specific chapter controls and root-level audio player through shared playback state so only one mobile bar renders at a time, without mounting a second audio element or resetting playback on chapter changes. Publish the active bar height once; update last-verse padding, scroll spacing, prompt offsets and safe-area spacing so install/update/offline messages never cover controls. The top header remains unchanged.
3. **Location peek from verses.** On mobile, tapping a verse location with a mapped place opens a roughly half-screen bottom sheet instead of immediately showing the generic context panel. It contains a draggable, interactive map centered on the selected place, the place name, one concise line of existing biblical context, a certainty note when location is approximate, and elevation only when a real terrain reading is available. If elevation is unavailable (including offline), say so rather than invent a value. Provide a visible expand control and an upward swipe to fill the screen; downward swipe returns to half-height or dismisses from half-height. Keep map gestures inside the map from moving the sheet. Escape, close and outside tap dismiss; focus returns to the triggering word.
4. **Reuse the atlas.** Use the existing place catalogue, Mapbox map surface and offline SVG fallback, lazy-mounted only after a mapped location is tapped. Do not create a new map system, geocoding request, or map instance on every sheet resize; resize the existing instance between peek and full-screen. Keep the existing full Maps link, reader return position, selected place, URL/deep-link behavior, and desktop context panel. For location mentions without a mapped place, retain the current context panel rather than showing an empty map.

## Technical details

- Playback currently lives in the root `AudioPlayer`; chapter navigation lives in `ReaderChrome`. Extract one shared playback controller/state and render a mobile combined control from the reader, while retaining one audio element and the existing desktop/global player. Audio auto-advance must use the current language-aware chapter route.
- `ChapterNavBar`, `AudioPlayer`, reader bottom padding, and coordinated prompts currently depend on `--chapter-nav-h` and `--audio-bar-h`. Use one active measured height in combined mode and zero the hidden bar's contribution, including small phones and safe areas.
- Verse location taps currently push an entry to `AtlasContext`, and `AtlasPanel` opens a mobile dialog. Resolve mapped place IDs with the existing catalogue; use a mobile-only map peek branch and preserve the stack/context links. The current catalogue has place coordinates, summaries and certainty but no recorded elevation values. The live map has a terrain source; sample elevation only when that source can return a real reading, otherwise display unavailable. The SVG relief is illustrative, not measured elevation.
- Constrain sheet swipes to its handle/header, not the map canvas or scrollable content. Keep the map mounted while changing sheet height and call its resize behavior after a snap transition. Honor reduced motion and dialog focus/scroll locking.

## Checks

- At 320, 375, 390, and 430px plus tablet/desktop: play, pause, pick a chapter, next/previous across book boundaries, seek and open audio options; verify one bar and no covered last verse or prompt.
- Tap mapped places such as Bethlehem and Samaria in real verses: half-height map is interactive, expansion/collapse/dismissal work, full Maps link and return-to-reading work, and uncertain locations are honestly labelled. Check unmapped mentions and offline/failed live-map fallback.
- Confirm no duplicate map or audio instances, no console errors, no broken language-prefixed chapter navigation, and unchanged desktop controls.
